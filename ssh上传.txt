第一步：创建本地仓库
# 进入项目文件夹
cd /c/Users/31737/Desktop/你的项目文件夹

# 初始化 Git 仓库（会生成 .git 文件夹）
git init

第二步：配置邮箱和名字（建议先做）
# 全局配置（一次设置，所有仓库生效）
git config --global user.email "你的邮箱@example.com"
git config --global user.name "你的名字"

第三步：绑定远程仓库（GitHub）
# 关联远程仓库（把本地和 GitHub 连起来）
git remote add origin git@github.com:用户名/仓库名.git

# 验证是否成功
git remote -v


第四步：添加文件并首次推送
# 1. 添加所有文件到暂存区
git add .

# 2. 提交到本地仓库
git commit -m "初始提交"

# 3. 推送到 GitHub（第一次需要加 -u）
git push -u origin main

第五步：以后修改上传（3步走）
①	git add .	添加修改的文件
②	git commit -m "描述"	提交到本地仓库
③	git push	推送到 GitHub
